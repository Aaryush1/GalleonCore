# lab (working notes, not for upstream)

Windows-side experiments toward live per-key lighting on the Galleon 100 SD (keyboard part `1b1c:2b0c`). Lives on the `key-lighting` branch of this fork only. Pull requests to upstream take findings from here and rewrite them to the project's conventions; this folder itself is never proposed upstream.

- `research/`: G0 notes from public sources (GalleonCore, OpenRGB, other Bragi implementations, Web Hub's front-end).
- `tools/Snap`: takes a photo from a camera pointed at the keyboard, so tests can check what the keys show.

Raw logs, captures and keyboard backups stay out of git (see `.gitignore` in this folder).
