Privacy policy

Last updated: 22 October 2026. Paul Woisard operates this project website. Privacy contact: privacy@galleoncore.xyz.

What this site does

This is a static website hosted by Cloudflare Pages. It has no account, payment form, advertising or visitor analytics. Cloudflare receives the technical requests needed to serve its pages and files, such as your IP address and browser information; Cloudflare determines its own handling and retention of those server logs. See the Cloudflare privacy policy. GitHub hosts the source code and downloadable releases; it receives your request data when you follow those links.

Distribution figures are generated from public GitHub, Launchpad, COPR and AUR package data in GitHub Actions. Direct-package baselines are refreshed daily; repository counts are checked weekly. These are aggregate package statistics, not a record of visits to this website or a way to identify its visitors.

Storage on your device

The site stores galleoncore-lang to remember your language and galleoncore-external-v1 to remember whether you allowed optional external content. These values stay in your browser's local storage until you change the choice or clear site data. The site does not set its own tracking cookies.

Optional external content

By default, status badges, web fonts and live download counts are not loaded from other sites. If you choose “Allow optional content”, your browser requests fonts from Google Fonts, badges from GitHub and Shields.io, and current release counts from the public GitHub API when you open the page. Those providers then receive ordinary request data such as your IP address and browser details, and apply their own policies. Refusing leaves local text labels, system fonts and the last daily direct-package snapshot; the site remains usable. Change your choice using “Privacy choices” below at any time. Links to external download or documentation sites are contacted only when you follow them.

You may also complain to the French data-protection authority, the CNIL. For data handled by Cloudflare, GitHub or another external provider, consult that provider's policy and contact channels.

Fonctionnement du site

Ce site statique est hébergé par Cloudflare Pages. Il ne propose ni compte, ni paiement, ni publicité, ni outil de mesure d’audience des visiteurs. Cloudflare reçoit les requêtes techniques nécessaires à la fourniture des pages et fichiers, notamment l’adresse IP et les informations du navigateur ; Cloudflare définit le traitement et la durée de conservation de ses journaux. Consulte la politique de confidentialité de Cloudflare. GitHub héberge le code source et les fichiers des releases ; il reçoit les données de ta requête lorsque tu suis ces liens.

Les chiffres de diffusion sont calculés dans GitHub Actions à partir de données publiques de GitHub, Launchpad, COPR et AUR. Les relevés des paquets directs sont quotidiens ; les compteurs des dépôts sont vérifiés chaque semaine. Ce sont des statistiques agrégées des paquets, pas un suivi des visites du site ni un moyen d’identifier ses visiteurs.

Stockage sur ton appareil

Le site enregistre galleoncore-lang pour conserver la langue choisie et galleoncore-external-v1 pour mémoriser ton choix concernant le contenu externe facultatif. Ces valeurs restent dans le stockage local du navigateur jusqu’à modification de ton choix ou effacement des données du site. Le site ne dépose pas de cookie de suivi propre.

Contenu externe facultatif

Par défaut, les badges d’état, les polices web et les compteurs en direct ne sont pas chargés depuis des sites tiers. Si tu choisis « Autoriser le contenu facultatif », ton navigateur demande les polices à Google Fonts, les badges à GitHub et Shields.io et les comptes des releases à l’API publique de GitHub à l’ouverture de la page. Ces fournisseurs reçoivent alors les données habituelles de la requête, dont ton adresse IP et les informations du navigateur, et appliquent leurs propres politiques. En refusant, les libellés locaux, les polices du système et le dernier relevé quotidien des paquets directs restent disponibles ; le site fonctionne. Tu peux changer d’avis avec « Choix de confidentialité » ci-dessous. Les liens de téléchargement et de documentation externes ne sont contactés que si tu les suis.
