# Firmware update illustration

`firmware-update.gif` is a screen recording provided by Paul Woisard on
21 October 2026 to illustrate the official Elgato Stream Deck firmware update
control for a Galleon 100 SD. The capture was supplied for publication in the
README and project website. The replacement supplied by the owner masks the
device serial number. No firmware binary or installer is distributed with this
repository.

The recording is credited to Paul Woisard under CC-BY-SA-4.0 in `REUSE.toml`.
Elgato and Corsair names and interface elements appear solely to identify the
official update control shown in the procedure.
