GalleonCore

Open-source Linux support for the Corsair Galleon 100 SD: its Stream Deck keys, screen and dials, customizable home widgets and automatic Gaming mode. Le support Linux libre du Corsair Galleon 100 SD : les touches, l'écran et les molettes de son Stream Deck, des widgets d’accueil personnalisables et un mode Gaming automatique.

Active development. The Stream Deck module works on Linux, with Galleon Bosun for settings. Version 0.2.0 brings home widgets and automatic Gaming mode to Linux and Windows; Plasma widgets remain planned. En développement actif. Le module Stream Deck fonctionne sous Linux, avec Galleon Bosun pour les réglages. La version 0.2.0 apporte les widgets d’accueil et le mode Gaming automatique sous Linux et Windows ; les widgets Plasma restent prévus.

Gaming: a dedicated screen while you playGaming : un écran dédié pendant tes parties

When a game is detected, automatic Gaming mode displays its artwork, FPS, CPU/GPU load gauges and available temperatures. It prevents the keyboard screensaver from starting during play. The Gaming pad controls appear while the game is active and disappear when it closes, even if you switch key pages during the session.Lorsqu’un jeu est détecté, le mode Gaming automatique affiche son image, les FPS, les jauges de charge CPU/GPU et les températures disponibles. Il empêche la veille du module pendant la partie. Les commandes Gaming du pad apparaissent pendant le jeu et disparaissent à sa fermeture, même si tu changes de page de touches entre-temps.

Choose Automatic, OBS or Game Bar in the Gaming tab. Automatic uses OBS on Linux and Game Bar on Windows; unavailable choices are disabled. OBS uses its local WebSocket connection for supported recording and replay actions with confirmed states. Game Bar uses keyboard shortcuts without claiming an unconfirmed recording state. Your choice is saved.Choisis Automatique, OBS ou Game Bar dans l’onglet Gaming. Automatique utilise OBS sous Linux et Game Bar sous Windows ; les choix indisponibles sont grisés. OBS passe par sa connexion WebSocket locale pour les actions d’enregistrement et de replay prises en charge, avec des états confirmés. Game Bar utilise des raccourcis clavier sans annoncer un état d’enregistrement non confirmé. Ton choix est mémorisé.

FPS capture on Linux and WindowsLa capture des FPS sous Linux et Windows

On Windows, Galleon detects the installed PresentMon service and uses its API without opening its interface. The capture control distinguishes installation, readiness and active capture. On Linux, Bosun prepares the MangoHud configuration and FPS folder, then provides instructions for Steam, Heroic, Lutris, PlayOnLinux and Bottles. A launcher setup is still required; detection becomes automatic on subsequent launches.Sous Windows, Galleon détecte le service PresentMon installé et utilise son API sans ouvrir son interface. Le bouton distingue l’installation, l’attente d’un jeu et la capture active. Sous Linux, Bosun prépare la configuration MangoHud et le dossier des FPS, puis explique les réglages pour Steam, Heroic, Lutris, PlayOnLinux et Bottles. Une configuration du lanceur reste nécessaire ; la détection devient ensuite automatique à chaque lancement.

Sensor availability depends on the hardware and drivers. NVIDIA uses NVML; AMD uses AMD-SMI or Linux hwmon. AMD ADLX is not yet integrated on Windows; optional local sensor providers may be needed for temperatures. The download widget counts partial files in the Downloads folder, rather than browser progress percentages. See the guides for Vulkan, DXVK, VKD3D-Proton and Flatpak limitations.Les capteurs disponibles dépendent du matériel et des pilotes. NVIDIA utilise NVML ; AMD utilise AMD-SMI ou hwmon sous Linux. Project scopePérimètre du projet

Stream Deck

Drive the 12 LCD keys, the screen and the two dials from Linux, without Elgato's software, which only runs on Windows and macOS. Piloter les 12 touches LCD, l'écran et les deux molettes depuis Linux, sans le logiciel d'Elgato, réservé à Windows et macOS.

Shared widgetsWidgets partagés

Write a widget once in QML: a clock, a system monitor, what's playing. It renders on the keyboard screen and sits on your KDE Plasma desktop. Écrire un widget une seule fois en QML : horloge, moniteur système, lecture en cours. Il s'affiche sur l'écran du clavier et sur ton bureau KDE Plasma.

RGB lightingÉclairage RVB

Per-key colours, the mood bar and the dial rings, through OpenRGB, so every OpenRGB user gets the support too. Couleurs par touche, barre d'ambiance et anneaux des molettes, via OpenRGB, pour que tous ses utilisateurs en profitent.

The first five pagesLes cinq pages initiales

A fresh Linux or Windows profile starts with Control, Multimedia, Video Games, System and Numeric Keypad. Each page holds at most 12 fixed keys. Multimedia suggests browsers and players first; System suggests administration tools; Video Games starts with installed Steam games. Labels and icons depend on what is installed on your computer. Unrelated applications do not fill empty slots, and editing or removing a key does not refill it.Un profil neuf sous Linux ou Windows commence avec Contrôle, Multimédia, Jeu Vidéo, Système et Pavé Numérique. Chaque page contient au plus 12 touches fixes. Multimédia propose d'abord les navigateurs et lecteurs ; Système, les outils d'administration ; Jeu Vidéo commence par les jeux Steam installés. Les noms et icônes dépendent de ce qui est installé sur ton ordinateur. Les applications sans rapport ne remplissent pas les places libres, et modifier ou retirer une touche ne la remplit pas à nouveau.

Existing personal profiles are preserved.Les profils personnels existants sont conservés.

How it fits togetherComment tout s'articule

libgalleon
The C++20 / Qt 6 library that talks to the keyboard. La bibliothèque C++20 / Qt 6 qui dialogue avec le clavier. Split in three layers: the protocol (pure functions, no I/O), the transport (HID access), and the deck logic. The protocol can be tested and fuzzed without the keyboard. LGPL-3.0, so other projects can reuse it. Découpée en trois couches : le protocole (fonctions pures, sans entrées/sorties), le transport (accès HID) et la logique du deck. Le protocole se teste et se fuzze sans le clavier. Sous LGPL-3.0, pour que d'autres projets puissent la réutiliser.
galleond
The daemon. It owns the keyboard, renders widgets for its screen and offers a D-Bus interface to the rest of the desktop. Le démon. Il possède le clavier, rend les widgets pour son écran et offre une interface D-Bus au reste du bureau.
WidgetsWidgets
Plain QML, with no Plasma dependency, so the same file runs inside galleond and inside a Plasma widget. Du QML pur, sans dépendance à Plasma : le même fichier tourne dans galleond et dans un widget Plasma.
RGB controllerContrôleur RVB
Developed in OpenRGB itself and proposed upstream, rather than in this repository. Développé dans OpenRGB lui-même et proposé en amont, plutôt que dans ce dépôt.

Checked on every changeVérifié à chaque modification

A driver reads bytes from hardware, which is where memory bugs hide. Every pull request has to pass these checks before it can land: Un pilote lit des octets venant du matériel, et c'est là que se cachent les bugs mémoire. Chaque pull request doit passer ces vérifications avant d'être fusionnée :

  • a build with GCC and Clang, strict warnings treated as errors;une compilation avec GCC et Clang, avertissements stricts traités en erreurs ;
  • the unit tests, also under AddressSanitizer and UndefinedBehaviorSanitizer;les tests unitaires, aussi sous AddressSanitizer et UndefinedBehaviorSanitizer ;
  • a minute of fuzzing on the input report parser;une minute de fuzzing sur le parseur des rapports d'entrée ;
  • clang-tidy, qmllint, and a REUSE licensing check.clang-tidy, qmllint, et une vérification des licences REUSE.
